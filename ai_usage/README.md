# Multimodal RAG Agent Documentation Pack

This folder contains token-efficient Markdown guidance for AI coding agents working on a multimodal RAG project.

## Start Here

Read `AGENTS.md` first.

Do not load every document for every task. Follow the routing instructions in `AGENTS.md` and read only the files relevant to the current change.

## Structure

- `AGENTS.md` — agent routing map
- `docs/ARCHITECTURE.md` — system boundaries and overall pipeline
- `docs/BUSINESS_FLOW.md` — end-to-end behavior
- `docs/DATA_CONTRACTS.md` — shared data shapes
- `docs/components/*` — component-specific guidance
- `docs/rules/*` — code, error, test, and security rules
